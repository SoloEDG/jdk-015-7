# Resonance

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:8015。

## 离线导出

「06 / OFFLINE EXPORT」把选定本地音频的一段，按指定分辨率与帧率逐帧渲染成 WebM。

- **可复现**：画面与时序只由「音频样本 + 导出设置 + 确认时刻的场景参数」决定。渲染在 Web Worker 里用 `OffscreenCanvas` + WebCodecs 完成，不依赖 `requestAnimationFrame`、窗口是否前台或机器是否卡顿；同一素材与设置重复导出得到逐字节相同的文件。
- **参数快照**：导出开始时深拷贝场景、主题、灵敏度、黑场/冻结等参数。之后在舞台上换场景或主题不会进入正在进行的导出。
- **现场不受影响**：导出期间舞台照常播放、切换与录制；取消只终止后台任务并删除半成品文件，不会重启现场音频。
- **分段渲染**：长素材按段生成，未压缩帧不会同时留在内存里。音频分析、场景过渡与运动相位都以导出时钟为自变量，跨段不重置；每段只向主线程索取所需的那一小片音频。
- **不静音兜底**：麦克风是实时输入，不可离线导出，面板会要求先录制或载入可重放素材。若所选区间缺少可重放样本，导出会失败并给出可定位的时间区间与帧范围，而不是把缺失区间渲染成静音。

导出文件通过随机写入保存在浏览器 OPFS 中，可随时下载；不支持 OPFS 的浏览器退化为内存输出并在面板中提示。
